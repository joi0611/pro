## 一、系统定位

- 面向中考英语「阅读理解」专项的网页训练系统，位于首页 `index.html` 的专项训练入口。
- 登录方式：输入登录码（Supabase 云验证），登录码绑定本专项，进度云端保存。
- 题库构成：内嵌 4 篇（A/B/C/D）+ 外部导入 53 个篇目（真题与模拟题），合计 57 篇，按篇目字母分组展示。
- 核心方法：**划 · 定 · 比 · 选** 四步训练法，把阅读题拆成可操作的思维流程。

## 二、核心方法论：划 · 定 · 比 · 选

### 第 1 步「划」——划关键词

- 双击题干中的单词即可选中/取消，选中的词作为「关键词」。
- 关键词优先级：
  - 疑问词类：who / where / when / why / what / how
  - 专有名词、数字时间、比较级和最高级（most / fastest…）
  - 隐身关键词：it / them 等代词指代对象也要留意
- 点击「确认关键词」后展示参考关键词与提示（keywordTip），帮助学生对比自己划的准不准。

### 第 2 步「定」——定位答案句

- 细节题：带着关键词回原文扫读，点击「定位答案句」后，系统在左侧文章高亮关键词与关键句（evidence）。
- 全局题（标题/主旨/结构/目的）：升级为「扫」——扫全文线索，展示：
  - 全文线索词（高频词、首尾句）
  - 核心线索句（首段首句、证据句、尾段末句）
  - 结构提醒（每段功能判断提示）

### 第 3 步「比」——对比答案句与选项

- 只显示原题选项，**不提前显示**正确项、干扰项标签或解析。
- 学生必须先主动选择一个答案，再点击「确认选择」；未选择时不能提交。
- 提交后本步只保留学生自己的选择，不公布正确答案。

### 第 4 步「复盘」——答案与解析

- 提交后展示：学生选择 vs 正确答案、对错反馈、解析（explanation）、关键依据（evidence）。
- 每个选项逐条列出「判断标签 + 判断依据」，帮助学生理解每个干扰项错在哪。
- 完整复盘在提交后统一出现，不在第 3 步提前泄露。

## 三、做题流程规则（交互约束）

1. **主动选择**：第 3 步必须先选答案再确认，未选不能提交。
2. **不剧透**：提交前不显示正确项、干扰项标签、解析；答案与解析全部放到第 4 步复盘。
3. **防跳过**：未完成第 3 步提交前，禁用「下一题」按钮。
4. **进度统计**：历史完成记录只用于题库进度统计（已完成 X/总数、正确率）；再次打开已做题目**不自动带入旧答案**，必须重新选择并确认。
5. **不悬浮**：做题页顶部信息区取消 sticky 悬浮，随页面正常滚动，不遮挡文章和题目。
6. **双版本同步**：相同的训练流程、真题排序和非悬浮逻辑同步到 `D:\赞顿学堂\training\reading\index.html`，原 UI、品牌、登录系统保持不变。

## 四、题型规则

| 题型 | 判定依据 | 处理方式 |
|---|---|---|
| 判断正误（A 篇） | 选项为 T / F | 题干为陈述句，判断与原文是否一致 |
| 四选一（B/C/D 篇） | 选项为 A. / B. / C. / D. | 标准选择题 |
| 词义猜测题 | 题干含 `underlined word / phrase`、`what does ... mean`、`probably mean` | 回到词所在句与上下文判断 |
| 全局题 | 题干含 `best title`、`mainly talks`、`main purpose`、`main idea`、`structure` | 走「扫全文线索」流程，不用单句定位 |
| 结构题 | 题干含 `structure` | 判断每段功能：提出问题 → 给出方法 → 说明效果 → 总结号召 |
| 图片题 | 题目数据带 `image` 字段 | 题干下方显示题图（如 42 题图片选项题、52 题结构图题） |
| 表格题 | 篇目带 `chart` 字段 | 文章区渲染表格材料（如部分 B 篇图表题） |
| 主旨/标题/目的题 | best title / main idea / main purpose | 看首段、尾段、高频词与全文中心，不能只看一句 |

### 全局题的「扫全文线索」细节

- 标题题：线索 = 首段首句 + 证据句 + 尾段末句；提示「标题要覆盖全文，不能只抓局部细节」。
- 主旨/主要谈论：线索 = 首句 + 证据 + 末句；提示「看首段、尾段和高频词」。
- 目的题：线索 = 证据 + 尾句；提示「看全文态度和结尾号召」。
- 结构题：线索 = 每段功能提示 + 结构信号词（Here's how / A good way / Next / Besides / In short / That's why / Finally 等）。

## 五、判断标签体系（对比标签）

### 细节题标签（detailCompareLabels）

`原词复现` · `同义替换` · `无依据` · `偷换对象` · `数字/时间错误` · `范围错误` · `反向表达`

### 全局题标签（globalCompareLabels）

`全文覆盖` · `只涵盖细节` · `范围过大` · `范围过窄` · `偏离主题` · `吸引力较弱` · `最佳标题`

### 结构题标签（structureCompareLabels）

`结构吻合` · `层次错分` · `方法段误判` · `总结段误判` · `无依据` · `最佳结构`

### 判断标签自动推断规则（inferCompareLabel）

- 正确答案：含同义/替换/对应等信号词 → `同义替换`，否则 `原词复现`
- 含偷换/混同/对象 → `偷换对象`
- 含数字/时间/地点/方向错 → `数字/时间错误`
- 含相反/反向/opposite → `反向表达`
- 含范围/过大/过小 → `范围错误`
- 其余 → `无依据`

```js
  paragraphVisuals: [...]          // 可选：段落配图

```

### 题目（q）字段

```js
function q(number, stem, options, answer, keywords, evidence, keywordTip, compare, explanation) {
  return { number, stem, options, answer, keywords, evidence, keywordTip, compare, explanation };
}
```

| 字段 | 含义 |
|---|---|
| `number` | 题号（与中考原卷题号一致，如 36–53） |
| `stem` | 题干 |
| `options` | 选项数组（T/F 或 A.–D.） |
| `answer` | 正确答案（T/F 或 A–D 字母） |
| `keywords` | 参考关键词数组 |
| `evidence` | 原文答案句（定位/高亮/复盘依据） |
| `keywordTip` | 关键词提示（为什么划这些词） |
| `compare` | 各选项判断依据数组（"A：…" / "B：…" 或 "T：…" / "F：…"） |
| `explanation` | 整题解析 |
| `image`（可选） | 题图地址，用 `Object.assign(q(...), { image })` 附加 |

### 排序与展示规则

- 篇目按字母 A/B/C/D 分组目录；真题（`isRealExam`，标题/元信息含年份真题）排前。
- 真题卡片带金色边框 + 「年份 新疆中考真题」徽章 + ★ 标记。
- 新增真题**不会覆盖**原有模拟题（按 id 去重追加）。

## 七、答案句定位算法（基座逻辑）

1. **精确匹配**：先在段落中直接查找 `evidence` 原文。
2. **句子切分**：按 `. ! ? 。！？` 切句；`Mr / Ms / Mrs / Dr / Prof / St`、`a.m./p.m.` 等缩略词不算句尾。
3. **模糊定位**：精确匹配失败时，对每个句子按「关键词命中数」打分（`scoreSentenceTerms`），取最高分句子。
4. **范围扩展**（`expandEvidenceSpanForQuestion`）：
   - 证据句含 `mean / means / because / so / is / helps / shows` 等释义词时，向前并入前一句；
   - 证据不足（术语命中 < 3）时，向后逐句并入后续句子，直到术语覆盖达标。
5. **停用词过滤**：a / the / and / it / this / which / following / passage 等约 40 个词不参与打分。
6. **同义词词典**（`synonymTerms`）：关键词 → 原文同义表达的高亮映射，如 popular→widely use、created→written、quiet→calm、lonely→company、quickly→fast、uneasy→nervous 等。

### 证据书写规约：跨段计数 / 列举题的 evidence 多句分段（2026-09-07 新增）

**适用范围**：题干需要从原文**多处、多段**累计信息才能得出答案的题，典型如——
- 数种类/数量，且答案项分散在不同段：`How many kinds of animals are mentioned?`（dogs 在第 2 段、apes 在第 3 段）；
- 排除式 "NOT / 未提到"：需列出原文**提到过的全部选项对应项**，供学生对照排除；
- 跨段列举某事物的优点/特点/手段。

**判断是否属此类**：答案依据是否**分布在不连续的多个句子/段落**。若原文一句话就给出全部依据（如 `300,000 runners`、`three parts`、`$1.19`、`three main kinds`），则**保持单句 evidence**，不要画蛇添足。

**书写格式**：把每处依据写成一条**原文精确句**，用「空格-斜杠-空格」` / ` 连接，末尾不再加多余省略号：

```
q(31, "How many kinds of animals are mentioned in the passage?",
  [...], "B", ["How many", "animals"],
  "Sometimes we see dogs play jokes on each other. / Scientists say they have watched young apes play jokes.",
  "数动物种类，跨段各取一句：dogs（第二段）+ apes（第三段），注意别只数到一段。", ...)
```

**要点**：
- 每一段必须是**原文原句**，不要用 `...` 做截断占位——截断会让单句定位算法只命中其中一句，漏掉其他支撑段（曾导致 2024 真题 D 篇 31 题只高亮 apes、漏 dogs）。
- `keywordTip` 明确提示"跨段各取一句 / 别只数到一段"，引导学生扫全。
- `compare` 里给错误项补一句"漏数某段"的错因，帮助复盘点破。

## 十、扩展约定（新增题目/篇目时）

1. 新篇目追加到 `imported-passages.js` 的 `add([...])` 中，id 不重复（按 id 去重）。
2. 严格只导入 A–D 篇；**不导入 E 篇、不导入五选五题型**。
3. 每题必须提供完整 9 字段（含 keywords / evidence / keywordTip / compare / explanation），否则复盘环节会缺信息。
4. **跨段计数 / 列举题**（如 how many kinds、NOT mentioned、跨段列举优点）：evidence 用「句1. / 句2.」分段把各处原文原句写全，禁止用 `...` 截断占位（详见第七节「证据书写规约」，曾致 2024真题D篇31题漏 dogs 段）。
5. 判断正误题 compare 用「T：… / F：…」格式；四选一用「A：… / B：…」格式。
6. 图片题用 `Object.assign(q(...), { image: "assets/xxx.png" })` 附加题图。
7. 表格材料篇目用 `chart: { columns, rows, note }`，题目按表格内容出。
8. 来源年份显示规则：模拟题按用户要求可统一显示为 2026。
9. 流程规则改动需同步到 `D:\赞顿学堂\training\reading\index.html`（保留其 UI/品牌/登录系统）。
